# Changelog

## 1.0.0 - 2026-07-16

- Initial public release.
- Added GeoLite2 country filtering and IP whitelist handling.
- Added IP2Proxy, ISP and CIDR-based VPN/proxy detection.
- Added temporary anti-bot bans, staff notifications and optional web sync.
- Added maintenance MOTD and access handling.
- Added clean shutdown handling, deterministic IP2Proxy sorting and atomic data-file writes.
- Updated the runtime and bytecode requirement to Java 25.
